# Automatic_classification_of_phraseological_units_in_a_multilingual_corpus
Проект в рамках программы ДПО "Компьютерная лингвистика" НИУ ВШЭ. Автоматическая многометочная классификация фразеологизмов с семантикой смерти (RU, SR, EN). Сравнение TF-IDF + Logistic Regression и XLM-RoBERTa, влияние дефиниций, кросс-языковой перенос. Бонус: генератор фразеологизмов.
