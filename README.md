# Automatic_classification_of_phraseological_units_in_a_multilingual_corpus
Проект в рамках программы ДПО "Компьютерная лингвистика" НИУ ВШЭ. Автоматическая многометочная классификация фразеологизмов с семантикой смерти (RU, SR, EN). Сравнение TF-IDF + Logistic Regression и XLM-RoBERTa, влияние дефиниций, кросс-языковой перенос. Бонус: генератор фразеологизмов.
# Автоматическая классификация фразеологизмов о смерти в многоязычном корпусе

Проект по компьютерной лингвистике: проверка возможности автоматизировать многометочную классификацию фразеологизмов с погребальной семантикой по типам метафорических переносов.

## Задача

Ручная разметка корпуса фразеологизмов занимает много времени и плохо масштабируется. Цель работы — сравнить подходы к автоматической классификации и понять:
- насколько реально автоматизировать разметку;
- помогают ли дефиниции;
- возможен ли перенос модели, обученной на русском, на другие языки без дообучения.

## Данные

- **Языки**: русский, сербский, английский
- **Исходный размер**: 986 фразеологизмов
- **После очистки**: 944
- **Русский корпус** (основной): 548 единиц
- **Разметка**: многометочная (15 категорий)
- **Наличие дефиниций**: у большинства единиц

### Категории (после нормализации)
`насилие`, `время`, `религия`, `тело`, `переход`, `позитивное`, `неизбежность`, `персона`, `мороз`, `вода`, `фольклор`, `земля`, `античка`, `воспитание`, `разрушение тела`

## Методы

### 1. Baseline
- **TF-IDF** + **One-vs-Rest Logistic Regression**
- Параметры: `ngram_range=(1,2)`, `min_df=2`, `C=2`, `class_weight='balanced'`

### 2. Нейросетевой подход
- **XLM-RoBERTa-base**
- `problem_type="multi_label_classification"`
- Learning rate = 1e-5, batch size = 8, 5 эпох
- Порог классификации = 0.2 (из-за низкой уверенности модели)

### 3. Эксперименты
- С дефинициями и без
- Кросс-языковой перенос (обучение только на русском -> тест на английском и сербском)

### 4. Бонус
Простой генератор новых фразеологизмов на основе шаблонов + морфологии (pymorphy3).

## Результаты

| Модель                  | F1 micro | F1 macro |
|-------------------------|----------|----------|
| TF-IDF                  | 0.473    | **0.354** |
| TF-IDF + дефиниции      | **0.577**| 0.126    |
| XLM-RoBERTa             | 0.422    | 0.181    |
| XLM-RoBERTa + дефиниции | 0.329    | 0.126    |

**Кросс-языковой перенос** (без дообучения):

| Язык     | F1 micro | F1 macro |
|----------|----------|----------|
| Сербский | 0.367    | 0.158    |
| Английский | 0.297  | 0.129    |

## Основные выводы

- На малом корпусе с сильным дисбалансом **TF-IDF оказался сильнее** XLM-RoBERTa.
- Дефиниции повышают F1 micro у TF-IDF, но сильно ухудшают macro (модель перекашивается в частые классы) и почти всегда вредят трансформеру.
- Кросс-языковой перенос возможен, лучше работает на близкие языки (русский → сербский).
- Полностью заменить лингвиста нельзя, но можно существенно сократить рутину за счёт лексических маркеров.
